# PassRouter

Paste a path and Finder goes there — including Windows paths like `\\server\share\folder` and `Z:\folder`.
パスを貼るだけで Finder が移動する Mac アプリです。Windows の共有フォルダのパス（`\\server\share`、`¥¥server¥share`、`Z:\`）にも対応します。
